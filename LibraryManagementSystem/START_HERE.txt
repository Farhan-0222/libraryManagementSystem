LIBRARY MANAGEMENT SYSTEM — FREE HOSTING PACKAGE

1. Read FREE_HOSTING_README.md first.
2. Push this folder to a GitHub repository.
3. Create a free MySQL-compatible TiDB Cloud Starter database and import database/library_db_cloud_import.sql.
4. Deploy this repository to Render using New > Blueprint (render.yaml).
5. Add DB_URL, DB_USER and DB_PASSWORD in Render Environment.
6. Open the generated onrender.com URL.

Important: Render Free sleeps after 15 minutes idle. TiDB has a monthly free quota. Do not use the demo credentials or this unmodified student project for real student records.
